# Luftkissenbahn

Virtuelles WebGL-Labor (Three.js) zur Luftkissenbahn für Physik in der Einführungsphase (NRW): beschleunigte Bewegung, Stoßversuche, Lichtschranken, Messprotokoll.

Live: https://erikdahlmann.github.io/luftkissenbahn/

## VR-Brille

Die Adresse im Browser der Brille öffnen (z. B. Pico) und auf „In VR starten“ tippen. Der Knopf erscheint nur auf Geräten mit WebXR. Bedienung: Strahl und Trigger, Stick nach vorn zum Springen, Stick zur Seite zum Drehen, Taste A oder X holt das Pult.
